## How each lab will be written

Every lab follows the same structure, so it reads like a short incident report:

1. **Objective**: what question the lab answers
2. **Environment**: what was running, which logs were collected
3. **Scenario**: the situation an analyst would be handed
4. **Simulation**: what was done in the lab to generate the activity
5. **Detection**: the search or rule used, and why it works
6. **Triage**: hypothesis, evidence, conclusion
7. **Lessons learned**: what I got wrong or would change

## Lab environment

Windows and Linux virtual machines on VirtualBox, with Windows Security and Sysmon logs collected in Splunk.
